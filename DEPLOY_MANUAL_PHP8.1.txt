คู่มือการติดตั้งและขึ้นโฮสต์ระบบสารสนเทศ (PHP 8.1 / Laravel 10)
กลุ่มงานสุขภาพดิจิทัล โรงพยาบาลทุ่งหัวช้าง จ.ลำพูน
เวอร์ชัน 2.2.2 (Build 20260910.1)
========================================================================

ไฟล์ที่ต้องใช้งาน (อยู่ในโฟลเดอร์ _deploy_moph):
1. it-system.zip      (ไฟล์ระบบหลักที่ผ่านการแปลงเป็น Laravel 10 และรองรับ PHP 8.1 แล้ว)
2. update-patch.zip   (ไฟล์แพตช์ขนาดเล็ก สำหรับอัปเดตระบบเดิมเป็น v2.2.2)
3. unzip.php          (สคริปต์ช่วยแตกไฟล์ it-system.zip รักษารูปแบบโครงสร้างโฟลเดอร์ 100%)
4. update.php         (สคริปต์ช่วยติดตั้งแพตช์ update-patch.zip ผ่านเบราว์เซอร์อัตโนมัติ)
5. info_test.php      (สคริปต์ทดสอบเวอร์ชัน PHP และ PHP Extensions บนโฮสต์)

------------------------------------------------------------------------
กรณีที่ 1: การติดตั้งระบบใหม่บนโฮสติ้ง (New Installation)
------------------------------------------------------------------------
1. ทดสอบสภาพแวดล้อม PHP:
   - อัปโหลด info_test.php ไปยังโฟลเดอร์ของระบบ
   - เปิดเบราว์เซอร์: http://<โดเมน>/info_test.php
   - ตรวจสอบว่า PHP เป็นเวอร์ชัน 8.1+ และเปิดใช้งาน Extensions:
     pdo_mysql, mbstring, openssl, curl, zip
   - เมื่อตรวจสอบเรียบร้อย ให้ลบไฟล์ info_test.php ออกทันที

2. แตกไฟล์ระบบด้วย unzip.php:
   - อัปโหลด it-system.zip และ unzip.php ขึ้นไปไว้ในโฟลเดอร์ปลายทาง
   - เปิดเบราว์เซอร์ไปที่: http://<โดเมน>/unzip.php
   - ระบบจะทำการแตกไฟล์และจัดวางโฟลเดอร์ให้อัตโนมัติ
   - เมื่อแตกเสร็จสิ้น ให้คลิกปุ่มลบไฟล์ หรือลบ it-system.zip และ unzip.php ออกจากโฮสต์ทันที

3. กำหนดค่าฐานข้อมูล (.env):
   - คัดลอกไฟล์ .env.example เป็น .env
   - แก้ไขการตั้งค่าฐานข้อมูล MySQL/MariaDB:
     DB_HOST=127.0.0.1
     DB_PORT=3306
     DB_DATABASE=ชื่อฐานข้อมูล
     DB_USERNAME=ผู้ใช้ฐานข้อมูล
     DB_PASSWORD=รหัสผ่านฐานข้อมูล

4. เริ่มต้นระบบและสร้างตารางฐานข้อมูล:
   - เปิดเบราว์เซอร์ไปที่:
     http://<โดเมน>/server-init?key=thc11143&migrate=1
   - ระบบจะทำการ:
     * เชื่อมโยงโฟลเดอร์ storage (storage:link)
     * ล้างแคชคอนฟิกและ Views (optimize:clear)
     * สร้างตารางฐานข้อมูลและรัน Migration ครบทุกตาราง (migrate --force)

5. เข้าสู่ระบบ:
   - เข้าหน้า Login ได้ที่: http://<โดเมน>/login
   - บัญชีเริ่มต้น: เข้าใช้งานด้วยบัญชีผู้ดูแลระบบที่กำหนดไว้

------------------------------------------------------------------------
กรณีที่ 2: การอัปเดตระบบเดิมที่มีอยู่แล้ว (Update Patch to v2.2.2)
------------------------------------------------------------------------
วิธีที่ 1 (ผ่านหน้าเว็บ Admin - แนะนำที่สุด):
1. เข้าสู่ระบบด้วยบัญชี Admin แล้วไปที่เมนู "ศูนย์ควบคุมการอัปเดตระบบ" (/system-updates)
2. อัปโหลดไฟล์ update-patch.zip
3. ระบบจะทำการสำรองข้อมูลอัตโนมัติ ติดตั้งแพตช์ และล้างแคชให้ทันที

วิธีที่ 2 (ผ่านสคริปต์ update.php):
1. อัปโหลด update-patch.zip และ update.php ขึ้นไปไว้ในโฟลเดอร์ของระบบ
2. เปิดเบราว์เซอร์ไปที่: http://<โดเมน>/update.php?key=thc11143
3. สคริปต์จะแตกไฟล์แพตช์โดยไม่แตะต้องไฟล์ .env หรือข้อมูล storage พร้อมล้างแคชและ migrate ให้อัตโนมัติ
4. ลบไฟล์ update-patch.zip และ update.php ออกจากเซิร์ฟเวอร์ทันที
